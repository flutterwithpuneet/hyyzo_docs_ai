# Hyyzo Support

## Getting Help

If you run into issues, here's how to get support:

### Community

- **GitHub Discussions** — Ask questions, share tips, and connect with other Hyyzo users.
- **Discord** — Join our community server for real-time help.

### Email

- **General inquiries**: hello@hyyzo.com
- **Technical support**: support@hyyzo.com
- **Enterprise sales**: enterprise@hyyzo.com

### Response Times

| Plan        | Response Time       |
|-------------|---------------------|
| Free        | Best effort (48h)   |
| Pro         | 24 hours            |
| Enterprise  | 4 hours (SLA)       |

## Reporting Bugs

Please include the following when reporting a bug:

1. Python version (`python --version`).
2. Operating system.
3. Steps to reproduce.
4. Relevant log output from `logs/hyyzo_docs_ai.log`.
5. Contents of your `.env` file (**without** the API key).

## Feature Requests

We welcome feature requests! Open a GitHub issue with the `enhancement` label and describe:

- What you'd like to see.
- Why it would be useful.
- Any implementation ideas you have.
