# Hyyzo Products

## Hyyzo Docs AI

An intelligent document assistant that reads your knowledge base and answers questions using Retrieval Augmented Generation (RAG). Upload Markdown, text, or PDF files and get accurate, source-referenced answers instantly.

### Key Capabilities

- Ingests `.md`, `.txt`, and `.pdf` documents.
- Creates vector embeddings for semantic search.
- Answers questions grounded in your documents — no hallucinations.
- Provides source references with every answer.

## Hyyzo Workflow

A no-code automation builder that connects your favourite tools (Slack, Jira, Gmail, GitHub) and triggers actions based on AI-classified events.

## Hyyzo Analytics

A real-time analytics dashboard that tracks team productivity, knowledge usage, and AI interaction patterns to surface actionable insights.
