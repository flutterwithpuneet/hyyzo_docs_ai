# Flutter Launcher Icons & Native Splash

This guide provides an end-to-end masterclass on configuring, generating, and maintaining **App Launcher Icons** (`flutter_launcher_icons`) and **Native Splash Screens** (`flutter_native_splash`) in Flutter (Android & iOS), including modern requirements like **Android 12+ Splash API**, **Adaptive Icons**, and **zero-flicker app bootstrapping**.

---

## 1. Why Dedicated Generators Are Essential

Without automated generators, configuring icons and splash screens requires manually generating dozens of resized image assets and updating native XML/Storyboard files:

| Platform | Manual Effort Required | With Automated Tools |
| :--- | :--- | :--- |
| **Android Icons** | 5+ mipmap density folders (`mdpi`, `hdpi`, `xhdpi`, `xxhdpi`, `xxxhdpi`), vector XMLs, adaptive icon foregrounds & backgrounds, themed monochromatic icons. | 1 source PNG $\rightarrow$ single CLI command. |
| **iOS Icons** | 15+ icon resolutions in `Assets.xcassets/AppIcon.appiconset` + `Contents.json` formatting without alpha transparency. | 1 source PNG $\rightarrow$ single CLI command. |
| **Android Splash** | Legacy `launch_background.xml`, `styles.xml`, and Android 12+ (`windowSplashScreenAnimatedIcon`, `windowSplashScreenBackground`) APIs. | YAML config $\rightarrow$ automated native XML setup. |
| **iOS Splash** | `LaunchScreen.storyboard` layout constraints and asset catalog scaling. | Auto-generated storyboard & constraints. |

## 2. Part 1: `flutter_launcher_icons` (Zero to Hero)

`flutter_launcher_icons` automates the generation of native app launcher icons for Android, iOS, Web, macOS, and Windows from a single source image.

### 2.1 Understanding Icon Safe Zones & Sizes

* **Recommended Source Image**: `1024 x 1024 px` PNG (Square, 300 DPI, no alpha/transparency for iOS).
* **Android Adaptive Icons Safe Zone**: Modern Android launchers crop icons into circles, squircles, or rounded rectangles.
  * Full canvas: `108 x 108 dp` (1024x1024 px source).
  * **Safe content zone**: Inner `72 x 72 dp` (approx. inner 66% area). Keep logos and text inside this safe zone to avoid clipping.

```
+---------------------------------------------------+
|               108dp / 1024px Canvas               |
|      +-------------------------------------+      |
|      |                                     |      |
|      |       Safe Zone (72dp / 680px)      |      |
|      |          [ Hyyzo Logo ]             |      |
|      |                                     |      |
|      +-------------------------------------+      |
|                                                   |
+---------------------------------------------------+
```

---

### 2.2 Configuration in `pubspec.yaml`

#### Standard Configuration (Hyyzo Setup)
```yaml
dev_dependencies:
  flutter_launcher_icons: ^0.14.4

flutter_launcher_icons:
  android: true
  ios: true
  image_path: "assets/images/appIcon/ic_launcher.png"
  adaptive_icon_background: "#FFFFFF"
  adaptive_icon_foreground: "assets/images/appIcon/ic_launcher.png"
```

#### Advanced / Hero Configuration (With Dark Mode & Monochromatic Themed Icons)
```yaml
flutter_launcher_icons:
  android: "launcher_icon"             # Custom name (default: ic_launcher)
  ios: true                           # Generates iOS AppIcon set
  image_path: "assets/images/appIcon/ic_launcher.png"
  
  # Android 8.0+ Adaptive Icons
  adaptive_icon_background: "#FFFFFF" # Solid color or asset path: "assets/images/appIcon/bg.png"
  adaptive_icon_foreground: "assets/images/appIcon/ic_launcher_foreground.png"
  
  # Android 13+ Themed / Monochromatic Icons (Material You)
  adaptive_icon_monochrome: "assets/images/appIcon/ic_launcher_monochrome.png"
  
  # Remove Alpha Channel for iOS (Apple rejects icons with transparency)
  remove_alpha_ios: true
  
  # Web / Desktop (Optional)
  web:
    generate: true
    image_path: "assets/images/appIcon/ic_launcher.png"
    background_color: "#FFFFFF"
    theme_color: "#FF6F00"
```

---

### 2.3 Running the Generator

Execute the command in the project root:

```bash
# Standard command
dart run flutter_launcher_icons

# Or using Flutter tool
flutter pub run flutter_launcher_icons
```

#### Multi-Flavor / Environment Icons (Dev / Staging / Prod)
If your app uses flavors (e.g., `flutter_launcher_icons-dev.yaml`, `flutter_launcher_icons-prod.yaml`):

```bash
dart run flutter_launcher_icons -f flutter_launcher_icons-dev.yaml
dart run flutter_launcher_icons -f flutter_launcher_icons-prod.yaml
```

## 3. Part 2: `flutter_native_splash` (Zero to Hero)

`flutter_native_splash` automatically creates and configures the native splash screen before Flutter's engine boots and the first frame renders, preventing blank white/black flashes.

### 3.1 Understanding the Android 12+ Splash API

Starting in Android 12 (API 31+), the system controls the splash screen using the **Splash Screen API**:
1. It displays an app icon centered on a window background color.
2. The icon is masked into a circle: **Icon must fit inside a circular mask of diameter 160dp (out of 288dp canvas)**.
3. Legacy Android (<12) uses traditional drawable layers and `launch_background.xml`.

`flutter_native_splash` supports **both** modern Android 12+ and legacy Android automatically.

---

### 3.2 Configuration in `pubspec.yaml`

#### Hyyzo Configuration
```yaml
dev_dependencies:
  flutter_native_splash: ^2.4.7

flutter_native_splash:
  color: "#ffffff"
  image: assets/images/appIcon/splash_icon.png

  android: true
  ios: true

  android_12:
    color: "#ffffff"
    image: assets/images/appIcon/splash_icon.png
```

#### Advanced / Hero Configuration (Dark Mode, Branding & Fullscreen)
```yaml
flutter_native_splash:
  # Base Light Theme
  color: "#FFFFFF"
  image: "assets/images/splash/splash_logo.png"
  branding: "assets/images/splash/powered_by_hyyzo.png"
  branding_mode: bottom              # Position at bottom
  
  # Dark Theme Support
  color_dark: "#121212"
  image_dark: "assets/images/splash/splash_logo_dark.png"
  branding_dark: "assets/images/splash/powered_by_hyyzo_dark.png"
  
  # Platform Targets
  android: true
  ios: true
  web: false
  
  # Android 12+ Specific Customization
  android_12:
    color: "#FFFFFF"
    color_dark: "#121212"
    image: "assets/images/splash/splash_logo_android12.png"
    icon_background_color: "#FFFFFF"
    icon_background_color_dark: "#121212"
    branding: "assets/images/splash/powered_by_hyyzo.png"
  
  # Screen Parameters
  fullscreen: true                   # Hides status bar and navigation bar during splash
  android_gravity: center            # Placement of image on legacy Android
  ios_content_mode: scaleAspectFit   # iOS image scaling mode
```

---

### 3.3 Running the Native Splash Generator

```bash
# Generate native splash screens
dart run flutter_native_splash:create

# Remove native splash and restore default Flutter template
dart run flutter_native_splash:remove
```

## 4. Seamless Splash to App Transition (Zero-Flicker)

By default, the native splash screen disappears as soon as Flutter draws its very first frame. However, if your app needs to initialize Firebase, Hive, SharedPreferences, or fetch initial BLoC data, users may see an empty/white screen for a second.

To achieve a **smooth zero-flicker transition**, use `FlutterNativeSplash.preserve()` and `FlutterNativeSplash.remove()`.

### 4.1 Step 1: Add dependency to `pubspec.yaml`
```yaml
dependencies:
  flutter_native_splash: ^2.4.7
```

### 4.2 Step 2: Implementation in `lib/main.dart`

```dart
import 'package:flutter/material.dart';
import 'package:flutter_native_splash/flutter_native_splash.dart';
import 'package:firebase_core/firebase_core.dart';
import 'package:hive_flutter/hive_flutter.dart';
import 'package:shared_preferences/shared_preferences.dart';

void main() async {
  // 1. Capture the WidgetsBinding instance
  WidgetsBinding widgetsBinding = WidgetsFlutterBinding.ensureInitialized();

  // 2. Preserve native splash screen while async services initialize
  FlutterNativeSplash.preserve(widgetsBinding: widgetsBinding);

  // 3. Perform heavy asynchronous bootstrapping
  await Firebase.initializeApp();
  await Hive.initFlutter();
  final prefs = await SharedPreferences.getInstance();
  
  // 4. Run the app
  runApp(const HyyzoApp());

  // 5. Dismiss splash once initialization is fully complete and first screen is ready
  FlutterNativeSplash.remove();
}
```

## 5. Summary of Key Files Modified in Native Projects

### Android Changes
* `android/app/src/main/res/drawable/launch_background.xml` (Legacy splash)
* `android/app/src/main/res/values/styles.xml` & `values-night/styles.xml` (Launch theme)
* `android/app/src/main/res/values-v31/styles.xml` (Android 12+ Splash API theme)
* `android/app/src/main/AndroidManifest.xml` (Theme reference in `<activity>`)

### iOS Changes
* `ios/Runner/Base.lproj/LaunchScreen.storyboard` (Visual UI Layout for native launch)
* `ios/Runner/Info.plist` (`UILaunchStoryboardName` set to `LaunchScreen`)
* `ios/Runner/Assets.xcassets/LaunchImage.imageset/` (Splash image assets)

## 6. Troubleshooting & Common Pitfalls

| Issue | Cause | Solution |
| :--- | :--- | :--- |
| **Android icon clipped / circular cut** | Important logo details are outside the `72dp` center safe area. | Add padding around the logo so the graphic stays within the center 66% area of the 1024x1024 canvas. |
| **Apple App Store Rejection: "Alpha channel not allowed"** | The iOS app icon has transparency. | Use solid background with no alpha, or add `remove_alpha_ios: true` in `flutter_launcher_icons`. |
| **Android 12 icon looks too small** | Android 12 limits the icon to a 160dp diameter circular viewport. | Supply a dedicated asset under `android_12.image` that fills the circular bounding box. |
| **Splash screen shows white flash before home screen** | Flutter drew the first empty frame before async dependencies finished loading. | Use `FlutterNativeSplash.preserve(widgetsBinding: widgetsBinding)` and call `FlutterNativeSplash.remove()` after bootstrapping. |
| **Old icon/splash still showing on device after rebuild** | Device OS (especially Android MIUI/OneUI & iOS springboard) aggressively caches app icons. | Uninstall the app from the device/simulator and perform a clean build: `flutter clean && flutter run`. |
